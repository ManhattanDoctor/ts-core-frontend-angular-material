Библиотека, предназначена для работы с компонентами пользовательского интерфейса в Angular. Она включает в себя различные модули, директивы и сервисы, которые упрощают создание интерактивных UI-элементов, таких как окна, уведомления, таблицы и элементы управления. Основные компоненты и их назначение:

1. **Модули**:
   - **VIModule**: Центральный модуль, который объединяет функциональность других модулей и предоставляет их в приложении.
   - **BottomSheetModule**: Обеспечивает функциональность для создания нижних листов (bottom sheets), которые могут отображать дополнительный контент поверх основного.
   - **WindowModule**: Предназначен для управления окнами, позволяя создавать, открывать и закрывать их, а также управлять их состоянием (минимизация, расширение и т.д.).

2. **Компоненты**:
   - **LanguageSelectorComponent**, **MenuListComponent**, **SelectListComponent**, **TabGroupComponent**: Компоненты для реализации различных элементов интерфейса.
   - **CdkTablePaginableComponent**, **CdkTableFilterableComponent**: Компоненты для отображения данных в виде таблиц с поддержкой пагинации и фильтрации.

3. **Директивы**:
   - **MenuTriggerForDirective**: Директива для управления поведением контекстного меню.
   - **VoiceRecognitionButtonDirective**: Директива для интеграции с функцией распознавания голоса, позволяющая активировать и деактивировать распознавание через события интерфейса.

4. **Сервисы**:
   - **BottomSheetService**: Сервис для управления нижними листами.
   - **WindowService**: Сервис для управления окнами, который включает возможность открытия новых окон, закрытия и управления их состоянием.
   - **NotificationService**: Сервис для управления уведомлениями, позволяющий создавать и отображать их в приложении.

5. **Пайпы**:
   - **CdkTableCellValuePipe**, **CdkTableCellClassNamePipe** и другие: Созданы для управления отображением данных в таблицах, позволяя легко формировать классы CSS и стили для ячеек в зависимости от данных.

Цель библиотеки заключается в упрощении разработки интерактивных пользовательских интерфейсов с помощью компонентов, которые легко интегрируются друг с другом и обеспечивают желаемый функционал, как для работы с окнами и уведомлениями, так и для управления отображением данных в таблицах.
